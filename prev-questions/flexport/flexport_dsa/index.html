    Flexport Interview DSA Questions (1–10) — Problems, Solutions & Explanations¶

    1. Push Dominoes¶

    Problem: Given a string of 'L', 'R', and '.', simulate the effect of domino pushes. Approach: Two passes — left-to-right to calculate rightward forces, right-to-left for leftward forces, compare to decide final state. Solution: 

    def pushDominoes(s):
    n = len(s); L = [0]*n; R = [0]*n
    force = 0
    for i,c in enumerate(s):
        force = 0 if c=='L' else (n if c=='R' else max(force-1,0))
        R[i] = force
    force = 0
    for i in range(n-1,-1,-1):
        c = s[i]
        force = 0 if c=='R' else (n if c=='L' else max(force-1,0))
        L[i] = force
    ans=[]
    for i in range(n):
        if R[i]==L[i]: ans.append('.')
        elif R[i]>L[i]: ans.append('R')
        else: ans.append('L')
    return ''.join(ans)
    Complexity: O(n) time, O(n) space.

    2. Hex-string Two Sum¶

    Problem: Given array of hex-string numbers and a hex target, return indices of two that sum to target. Approach: Convert to int, use hashmap for complement lookup. Solution: 

    def two_sum_hex(nums, target_hex):
    target = int(target_hex, 16)
    seen = {}
    for i,xh in enumerate(nums):
        x = int(xh, 16)
        if target - x in seen:
            return [seen[target-x], i]
        seen[x] = i
    Complexity: O(n) time, O(n) space.

    3. Directed Graph Traversal / Cycle Detection¶

    Problem: Given directed edges, detect cycles. Approach: DFS with 3-color marking. Solution: 

    def has_cycle(n, edges):
    g = [[] for _ in range(n)]
    for u,v in edges: g[u].append(v)
    color = [0]*n
    def dfs(u):
        color[u]=1
        for v in g[u]:
            if color[v]==1: return True
            if color[v]==0 and dfs(v): return True
        color[u]=2; return False
    return any(dfs(u) for u in range(n) if color[u]==0)
    Complexity: O(n+m).

    4. Validate IP Address¶

    Problem: Given a string, classify as IPv4, IPv6, or Neither. Approach: Split and validate by rules for each IP type. Solution: 

    def validIPAddress(q):
    import string
    hexd = set(string.hexdigits)
    def v4(s):
        parts = s.split('.')
        if len(parts)!=4: return False
        for p in parts:
            if not p or (len(p)>1 and p[0]=='0'): return False
            if not p.isdigit(): return False
            x = int(p)
            if x<0 or x>255: return False
        return True
    def v6(s):
        parts = s.split(':')
        if len(parts)!=8: return False
        for p in parts:
            if not (1<=len(p)<=4): return False
            if not all(c in hexd for c in p): return False
        return True
    return "IPv4" if v4(q) else ("IPv6" if v6(q) else "Neither")
    Complexity: O(len(s)).

    5. Letter Combinations of a Phone Number¶

    Problem: Map digit string to all possible letter combinations. Approach: Iterative expansion. Solution: 

    def letterCombinations(digits):
    if not digits: return []
    M = {'2':'abc','3':'def','4':'ghi','5':'jkl','6':'mno','7':'pqrs','8':'tuv','9':'wxyz'}
    ans=['']
    for d in digits:
        ans = [p+c for p in ans for c in M[d]]
    return ans
    Complexity: O(∏ choices).

    6. Tile Removal Game¶

    Problem: Remove contiguous runs of ≥3 identical tiles repeatedly. Approach: Stack to track character and count, remove when count ≥3. Solution: 

    def crush(s):
    st=[]
    for ch in s:
        if st and st[-1][0]==ch:
            st[-1][1]+=1
            if st[-1][1]>=3:
                st.pop()
        else:
            st.append([ch,1])
    return ''.join(ch*cnt for ch,cnt in st)
    Complexity: O(n).

    7. Token–Card Purchase Logic¶

    Problem: Determine if a player can buy a card given tokens, wildcards, and bonuses. Approach: Calculate deficits after bonuses, use wildcards if needed. Solution: 

    def can_buy(tokens, wild, cost, bonus):
    deficit = 0
    pay = {}
    for c in cost:
        need = max(0, cost[c] - bonus.get(c,0))
        use = min(tokens.get(c,0), need)
        pay[c]=use
        deficit += (need - use)
    return (deficit <= wild), pay, wild - deficit
    Complexity: O(colors).

    8. Reservation System¶

    Problem: Book non-overlapping intervals for each resource. Approach: Maintain sorted list per resource, binary search for placement. Solution: 

    import bisect
class Scheduler:
    def __init__(self): self.map={}
    def book(self, rid, start, end):
        A = self.map.setdefault(rid, [])
        i = bisect.bisect_left(A, (start,end))
        if i>0 and A[i-1][1] > start: return False
        if i<len(A) and A[i][0] < end: return False
        A.insert(i,(start,end)); return True
    Complexity: O(log n) search.

    9. Connect Four (Infinite Board)¶

    Problem: Place a piece and detect if player wins (4 in a row). Approach: Count in 4 directions from placed position. Solution: 

    dirs=[(1,0),(0,1),(1,1),(1,-1)]
def win(board, r,c,p):
    def count(dr,dc):
        k=0; rr,cc=r+dr,c+dc
        while (rr,cc) in board and board[(rr,cc)]==p:
            k+=1; rr+=dr; cc+=dc
        return k
    for dr,dc in dirs:
        if 1+count(dr,dc)+count(-dr,-dc) >= 4:
            return True
    return False
    Complexity: O(1) per move.

    10. Checkers (Core Move Logic)¶

    Problem: Generate legal moves in checkers, prioritizing captures. Approach: DFS for capture chains, normal moves if no captures. Solution (outline): 

    def gen_moves(board, player):
    captures = []
    normals = []
    for p in all_pieces(board, player):
        caps = find_captures(board, p)

    11. Median-Finding¶

    Problem: Find the median from a stream of numbers. Approach: Use two heaps — max-heap for lower half, min-heap for upper half — to balance elements. Solution: 

    import heapq
class MedianFinder:
    def __init__(self):
        self.low, self.high = [], []  # max-heap (invert sign) and min-heap
    def addNum(self, num):
        heapq.heappush(self.low, -num)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.low) < len(self.high):
            heapq.heappush(self.low, -heapq.heappop(self.high))
    def findMedian(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2
    Complexity: O(log n) insert, O(1) median retrieval.

    12. Implement a Sorting Algorithm¶

    Problem: Implement quicksort from scratch. Approach: Choose pivot, partition, recursively sort halves. Solution: 

    def quicksort(a):
    if len(a) <= 1: 
        return a
    pivot = a[len(a)//2]
    left = [x for x in a if x < pivot]
    mid  = [x for x in a if x == pivot]
    right = [x for x in a if x > pivot]
    return quicksort(left) + mid + quicksort(right)
    Complexity: O(n log n) average, O(n^2) worst-case.

    13. Graph Traversal Implementation¶

    Problem: Traverse graph using BFS. Approach: Use queue to process nodes level by level. Solution: 

    from collections import deque
def bfs(graph, start):
    vis = set([start])
    q = deque([start])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            if v not in vis:
                vis.add(v)
                q.append(v)
    return order
    Complexity: O(V+E).

    15. Binary Search on Answer¶

    Problem: Given weights and days, find minimal ship capacity to deliver in D days. Approach: Binary search between max(weights) and sum(weights); greedily check feasibility. Solution: 

    def shipWithinDays(weights, D):
    lo, hi = max(weights), sum(weights)
    def can(cap):
        days, total = 1, 0
        for w in weights:
            if total + w > cap:
                days += 1
                total = 0
            total += w
        return days <= D
    while lo < hi:
        mid = (lo+hi)//2
        if can(mid):
            hi = mid
        else:
            lo = mid+1
    return lo
    Complexity: O(n log(sum-max)).

    16. Dynamic Programming – Coin Change¶

    Problem: Find the fewest coins needed to make a target amount. Approach: Bottom-up DP tracking minimal coins for each total. Solution: 

    def coinChange(coins, amount):
    dp = [float('inf')] * (amount+1)
    dp[0] = 0
    for i in range(1, amount+1):
        for c in coins:
            if i-c >= 0:
                dp[i] = min(dp[i], dp[i-c]+1)
    return dp[amount] if dp[amount] != float('inf') else -1
    Complexity: O(amount * len(coins)).

    17. Graph: DFS Basics¶

    Problem: Perform a depth-first search on a graph. Approach: Use recursion or explicit stack to visit nodes. Solution: 

    def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    for v in graph[start]:
        if v not in visited:
            dfs(graph, v, visited)
    return visited
    Complexity: O(V+E).

    20. Permission or Simulation Logic¶

    Problem: Simulate a system with state transitions based on actions. Approach: Map states to allowed transitions; iterate through action sequence. Solution: 

    def simulate(actions, rules, start_state):
    state = start_state
    for act in actions:
        if act in rules[state]:
            state = rules[state][act]
        else:
            return False
    return True
    Complexity: O(len(actions)).

    21. Merge K Sorted Lists¶

    Problem: Merge k sorted linked lists into one sorted list. Approach: Use a min-heap to repeatedly extract the smallest head node. Solution: 

    import heapq
def mergeKLists(lists):
    heap = []
    for i, node in enumerate(lists):

    dummy = curr = ListNode(0)

    22. Sliding Window — Longest Substring Without Repeating Characters¶

    Problem: Given a string, find the length of the longest substring without repeating characters. Approach: Use a sliding window with a hashmap to track indices. Solution: 

    def lengthOfLongestSubstring(s):
    seen = {}
    left = max_len = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1
        seen[ch] = right
        max_len = max(max_len, right - left + 1)
    return max_len
    Complexity: O(n) time, O(k) space.

    23. Monotonic Stack — Largest Rectangle in Histogram¶

    Problem: Find largest rectangle area in histogram bars. Approach: Use stack to maintain increasing bar heights. Solution: 

    def largestRectangleArea(heights):
    stack = []
    max_area = 0
    heights.append(0)
    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
    Complexity: O(n).

    24. Union-Find — Connected Components¶

    Problem: Given n nodes and edges, count connected components. Approach: Union-Find data structure. Solution: 

    def countComponents(n, edges):
    parent = list(range(n))
    def find(x):
        while x != parent[x]:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[ra] = rb
    for u, v in edges:
        union(u, v)
    return len({find(i) for i in range(n)})
    Complexity: O(α(n)) amortized.

    25. Trie — Autocomplete¶

    Problem: Implement a trie with insert and search (prefix match). Approach: Each node stores children and end-of-word flag. Solution: 

    class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True
    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end
    def startsWith(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True
    Complexity: O(L) per op, where L is word length.

    26. Interval Merge¶

    Problem: Merge overlapping intervals. Approach: Sort by start, merge into output list. Solution: 

    def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    merged = []
    for start, end in intervals:
        if not merged or merged[-1][1] < start:
            merged.append([start, end])
        else:
            merged[-1][1] = max(merged[-1][1], end)
    return merged
    Complexity: O(n log n).

    27. Grid DP — Unique Paths¶

    Problem: Find unique paths from top-left to bottom-right in m×n grid. Approach: DP table where dp[i][j] = dp[i-1][j] + dp[i][j-1]. Solution: 

    def uniquePaths(m, n):
    dp = [[1]*n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[-1][-1]
    Complexity: O(mn).

    28. Longest Increasing Subsequence (n log n)¶

    Problem: Find LIS length. Approach: Patience sorting using binary search. Solution: 

    import bisect
def lengthOfLIS(nums):
    sub = []
    for x in nums:
        i = bisect.bisect_left(sub, x)
        if i == len(sub):
            sub.append(x)
        else:
            sub[i] = x
    return len(sub)
    Complexity: O(n log n).

    29. Topological Sort — Course Schedule¶

    Problem: Given prerequisites, find if all courses can be finished. Approach: Kahn's algorithm (BFS on in-degree). Solution: 

    from collections import deque
def canFinish(numCourses, prerequisites):
    g = [[] for _ in range(numCourses)]
    indeg = [0]*numCourses
    for u,v in prerequisites:
        g[v].append(u)
        indeg[u]+=1
    q = deque([i for i in range(numCourses) if indeg[i]==0])
    visited = 0
    while q:
        u = q.popleft()
        visited+=1
        for v in g[u]:
            indeg[v]-=1
            if indeg[v]==0:
                q.append(v)
    return visited == numCourses
    Complexity: O(V+E).

    30. BFS/DFS on Grid — Number of Islands¶

    Problem: Count islands in a binary grid. Approach: DFS or BFS flood-fill from each unvisited '1'. Solution: 

    def numIslands(grid):
    if not grid: return 0
    m, n = len(grid), len(grid[0])
    def dfs(i, j):
        if i<0 or i>=m or j<0 or j>=n or grid[i][j] != '1':
            return
        grid[i][j] = '0'
        for di, dj in [(1,0),(-1,0),(0,1),(0,-1)]:
            dfs(i+di, j+dj)
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                dfs(i, j)
                count += 1
    return count
    Complexity: O(mn).
